# JevManager 项目界面约定

本文件保留项目职责和实现映射。通用字体、颜色、尺寸、控件状态及视觉验收通过用户级 `$macos-ui-standards` skill 在明确调用时应用；AGENTS.md 不自动要求读取它。

## 页面职责

权威行为见 [首版规格](spec.md#2026-10-05-用户修订职责与视觉)，术语见 [CONTEXT.md](../CONTEXT.md)。

- 搜索按模型包和变体选择，文件关联属于内部处理与详情；下载来源和模型库目录在设置，下载任务页展示实际任务。
- 引擎页管理安装、删除和本机关联；模型库运行入口选择引擎并执行真实兼容性核验。
- UI 呈现实际业务状态；搜索、安装、兼容和就绪分别表达。首层保留名称、属性、状态与操作，详细诊断按需展开。
- 桌面与 MCP 共用委员会入口和实例。窗口、明确退出及受管/接入实例归属按 [生命周期规格](spec.md#mcp-与应用生命周期) 执行，UI skill 不改变这些行为。

## 实现与角色映射

主题入口为 `lib/app_theme.dart`，公共组件继续从此复用。调用 skill 时映射下列角色，按本次修改范围逐步对齐；既有界面不因此自动成为已验收结果。

| 项目角色 | 主题接口 | Apple 文本角色 |
| --- | --- | --- |
| 主内容标题 | `headlineSmall` | Title 1 |
| 区域标题 | `titleMedium` | Title 3 |
| 列表正文 | `bodyMedium` | Body |
| 辅助信息 | `bodySmall` / `labelMedium` | Callout |
| 输入提示 | `inputDecorationTheme.hintStyle` | 辅助文字语义 |

## 验收记录

产品行为检查按规格执行。用户调用 UI skill 时，另按该 skill 验证受影响的布局、状态及视觉表现，并把实际尺寸、主题、版本、截图和未验证项记录到相关 `docs/verification/` 文档。
