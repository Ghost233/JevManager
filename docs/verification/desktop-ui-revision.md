# 2026-10-05 桌面职责与视觉修订

对应用户对搜索、下载、引擎管理与视觉层级的反馈。

## 已实现

- 搜索框采用统一灰色占位文本；HF 任意关键词搜索，模型名、作者和下载量分层显示。搜索前不显示空列表表头和整块空详情卡。
- 中性灰背景与面板，蓝色仅用于主要操作与选中项；标题 22、项目标题 15、正文 13、元信息 12、状态 11。固定页边距、行距和面板间隔。
- 模型库将模型名与发布者分开，缩减固定列宽，为长名称保留空间。设置内容限制最大宽度，操作与对应设置对齐。
- 下载默认来源仅在设置保存。点击模型包“下载”时固定来源、目录与修订；下载页展示真实任务状态与来源记录。
- 引擎页仅安装、删除和关联现有引擎；本地关联可以选 LM Studio 的标准 llama-server 目录。运行时在模型库弹窗选择具体引擎。

## 实际验证

原生 Flutter release 编译成功，产物 `build/macos/Build/Products/Release/JevManager.app`（最终构建 44.3 MB）。退出旧进程并核验 isRunning=false 后重新打开。CUA 检查真实原生窗口，验证搜索提示灰度与空态、设置的唯一来源入口，以及页面字体和间距。

实际 HF 搜索 `Kev-0.8B` 得到 23 个结果，选择 `ggml-org/Kev-0.8B-GGUF`，界面选择 `GGUF · Q8_0`（不是文件复选框），点击下载后自动转到真实任务，校验已有共享库文件后显示“已完成 / 本地文件复用”。

原生引擎管理页刷新后显示两项真实登记（官方安装与 LM Studio 目录的本地关联），无独立 LM Studio 连接页或令牌表单；模型库“运行”弹窗可选择这两项引擎，取消后保留原文件。最终构建已重新打开：管理页标题与导航一致；关联项显示“llama.cpp · LM Studio 2.50.0”，真实 commit 与归属放在辅助灰色行，删除操作用红色。运行选择项拆为引擎名称和版本/归属两行，已实际点击关联项并看到选中值变为“llama.cpp · LM Studio 2.50.0 / 0.5.0-dev · d775ebf · 本地关联”，然后取消弹窗；完整路径仍保留在详情中。最终容器全套 94 项测试通过（run-Zyk3YV），静态检查无问题（run-7kNSmL），包含所有本轮冻结的 UI 文件。此记录不表示 MCP、退出生命周期与完整中文效果验收已经完成。
