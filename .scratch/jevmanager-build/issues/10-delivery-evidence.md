# 10 — 中文对照闭环与本机应用交付

**要构建什么：** 用户得到可直接运行的正式 macOS .app 和完整闭环证据：搜索下载、共享库识别、真实引擎、两席并发、Codex MCP、生命周期，以及中文案例对照。依据 [首版规格](../../jevmanager/spec.md)，本工单汇总完整交付，不能替此前切片补掉全部测试。

**被什么阻塞：** [02 — 下载所选资产到用户模型库](02-download-install.md)；[09 — 关窗继续与明确退出的正确收尾](09-background-lifecycle.md)。

**状态：** ready-for-agent

- [ ] 正式 .app 可在目标 Mac 运行，使用用户指定工具链与模型路径，紧凑 UI 满足 oMLX 参考、HF 搜索、无教程和少说明约束。
- [ ] 搜索/下载、共享文件、资产识别、引擎能力与运行、委员会、MCP 和生命周期均有各自真实验收证据，不以原型或替身代替。
- [ ] 两种不同真实模型及委员会在同一 12 个中文合成案例上对照，记录正确首选、并列、重排变化和失败，不隐藏综合弱于单模型。
- [ ] 记录具体模型/引擎/客户端版本、冷启动和热咨询、样本数、延迟及实际可测内存口径；未测数据明确未测。
- [ ] 中文案例不是训练集或真实业务证据，不承诺未获数据支持的泛化、校准或独立性收益。
- [ ] 容器通用测试与 Mac 编译/真实联调的结果分开记录；所有上游切片自身验收仍成立。
- [ ] 不开展 App Store、公证、公开分发、云托管或额外桌面平台，也不把示例服务状态当正式实现。
- [ ] 交接运行方法、已知限制和准确的本地/远端 Git 状态；不为同步移动、stash 或覆盖用户未提交内容。
