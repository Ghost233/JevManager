# 08 — Codex 通过本机 HTTP MCP 咨询委员会

**要构建什么：** 应用提供真实本机 HTTP MCP，Codex 能发现并调用 consult_jev_council，实际收到各席位意见、综合、分歧和故障。依据 [首版规格](../../jevmanager/spec.md)，复用已有业务逻辑与常驻实例，不创建另一套模型或综合算法。

**被什么阻塞：** [07 — 超时、无效响应和部分结果的完整返回](07-partial-failures.md)。

**状态：** ready-for-agent

- [ ] 提供实际 loopback Streamable HTTP 服务及真实接入配置，模型推理 REST 不冒充 MCP。
- [ ] SDK/协议选择与实际 Codex 可验证版本匹配，不混用新旧协商及调用字段。
- [ ] 工具发现不等全部模型冷加载，输入为 state 与稳定 ID 的 options，工具只咨询不执行候选行动。
- [ ] 结构化结果含每席、综合、分歧和失败，文本兼容内容表达同一结果，单席/零席模式不伪装。
- [ ] 多个客户端共用常驻实例，连接与断开不重复加载或自动卸载模型。
- [ ] 容器协议/业务测试覆盖工具发现、调用、无效输入及部分失败；本地访问边界满足所选协议要求。
- [ ] Codex 实际发现、调用并消费结果，有脱敏证据；仅配置名称或服务器健康不算完成。
