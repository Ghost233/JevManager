# 09 — 关窗继续与明确退出的正确收尾

**要构建什么：** 用户关闭管理窗口后 Codex 仍可咨询，重新打开窗口能管理原有实例；明确退出时停止本应用服务和受管实例，保留 LM Studio 本身与接入实例。依据 [首版规格](../../jevmanager/spec.md)，以实际服务生命周期验收，不只改变窗口回调。

**被什么阻塞：** [08 — Codex 通过本机 HTTP MCP 咨询委员会](08-codex-mcp.md)。

**状态：** ready-for-agent

- [ ] 关闭最后窗口保留应用、实例和 MCP，原客户端及后续调用仍可用。
- [ ] 重新打开窗口能看到真实原状态，不重复加载模型或创建另一套服务。
- [ ] 明确退出先拒绝新请求，再正确收口进行中的咨询、MCP 与受管实例。
- [ ] 只停止本应用启动的独立进程或经公开接口创建并准确记录的受管实例；LM Studio 和原有接入实例保留。
- [ ] 退出后没有本应用遗留的独立引擎，首版不建立退出后继续运行的独立后台服务。
- [ ] 容器行为测试覆盖归属与收尾逻辑；Mac 窗口、真实进程/实例和 Codex 连接分别联调验证。
