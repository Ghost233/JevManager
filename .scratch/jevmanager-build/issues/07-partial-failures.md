# 07 — 超时、无效响应和部分结果的完整返回

**要构建什么：** 某席位慢、不可用、连接失败或返回非法数据时，用户仍能看到有效意见和真实故障覆盖范围；大模型可区分完整委员会、单模型和无有效结果。依据 [首版规格](../../jevmanager/spec.md)，将失败行为完整贯穿业务结果和界面。

**被什么阻塞：** [06 — 两席真实并发咨询与等权综合](06-concurrent-council.md)。

**状态：** ready-for-agent

- [ ] 默认整轮 10 秒截止，全成功可提前返回；未就绪、超时和失败席位都有明确结果。
- [ ] 缺候选、错位、非法概率、不同候选集和无定义分数不悄悄加入综合。
- [ ] 全部成功为 ok，存在有效意见但有失败为 partial，零有效为 failed，不省略失败来伪造 ok。
- [ ] 至少两席成功为 ensemble；单席成功为 single_model 且综合为空；零席为 none 且无编造建议。
- [ ] 截止后停止等待，晚到结果不改已返回结果，取消不杀常驻引擎或其他调用。
- [ ] 界面简短显示每席状态、综合/空综合和分歧，原始细节按需展开，不增加教程。
- [ ] 容器行为测试覆盖超时、取消、晚到、非法响应、全部/部分/单席/零席结果；真实停用一席后的结果另行验证。
