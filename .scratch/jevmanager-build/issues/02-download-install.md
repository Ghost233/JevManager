# 02 — 下载所选资产到用户模型库

**要构建什么：** 用户从 HF 搜索/文件列表选择具体资产和量化，设置可与 LM Studio 共用的目录与下载来源，观察真实下载、校验和完成安装；中断、失败和恢复也能通过界面处理。遵守 [首版规格](../../jevmanager/spec.md)，下载完成不冒充引擎就绪。

**被什么阻塞：** [01 — 紧凑桌面里的 HF 搜索与文件浏览](01-hf-search-files.md)。

**状态：** ready-for-agent

- [ ] 下载所选文件及必要配套资产，记录来源、固定 revision、大小和可用校验和，不自动下载全部量化。
- [ ] 用户可设置模型库路径，切换 HF 直连和 LM Studio 代理；实际失败如实呈现。
- [ ] 真实进度、临时文件和正式安装分开，必要文件及可用校验通过后才完成安装。
- [ ] 中断恢复仅在来源支持续传且版本仍匹配时进行；不支持、版本变化或校验失败有明确结果。
- [ ] 同名正式文件不被自动覆盖，失败和取消不改变既有共享资产。
- [ ] 经共用业务入口的容器测试覆盖文件变化、版本、校验、中断和冲突；真实下载与来源能力另行验收。
- [ ] 可独立演示从搜索选择到真实安装的闭环，不将小文件代理验证写成大权重通过。
