# 01 — 紧凑桌面里的 HF 搜索与文件浏览

**要构建什么：** 用户在正式 Flutter macOS 应用中按关键词或仓库搜索 Hugging Face，查看真实文件、revision、格式和大小。参考 oMLX 的紧凑导航与表格，没有初始化教程、大段说明、固定品牌下载入口或模拟成功。这是正式应用的第一条完整路径，建立桌面和后续 MCP 共用的业务入口及容器行为测试路径；依据 [首版规格](../../jevmanager/spec.md)，不直接提升旧原型。

**被什么阻塞：** 无，可立即开始。

**状态：** ready-for-agent

- [ ] 关键词和仓库输入能返回真实 HF 数据，结果不依赖预置模型列表。
- [ ] 选中仓库可以浏览真实文件、revision、格式与大小；没有数据和请求失败有简短状态。
- [ ] 原型中的三方案切换器、步骤教程、巨大展示区和模拟状态不出现在正式界面。
- [ ] 共用业务入口负责行为，UI 不持有另一套下载/模型逻辑；测试不增加专用业务接口。
- [ ] 行为测试经该入口使用受控 HF 响应覆盖检索、选择、无结果、失败和字段映射，在容器中通过。
- [ ] Mac 编译与真实 HF/桌面联调按已允许的范围完成，截图或操作结果能证明该路径。
