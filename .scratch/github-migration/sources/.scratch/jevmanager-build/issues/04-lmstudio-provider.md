# 04 — LM Studio 接入与实例能力检查

**要构建什么：** 用户在应用中关联 LM Studio，查看真实 runtime/版本、模型和实例，检查选定模型安装是否具备实际 decision 能力，并区分受管与接入实例。依据 [首版规格](../../jevmanager/spec.md)，优先复用公开接口，不预设 LM Studio 必然支持该资产。

**被什么阻塞：** [03 — 共享模型库的扫描、识别与手动删除](03-shared-library.md)。

**状态：** ready-for-agent

- [ ] 经公开 CLI/SDK/REST/runtime 管理入口关联，显示实际提供方、版本和实例标识，不直接依赖捆绑内部 binary。
- [ ] 能连接、不能连接、不支持、待验证和真实就绪有准确结果；不支持判定是能力结论，不伪造成功。
- [ ] 对具体模型/引擎组合检查 typed 请求与实际概率响应；普通聊天结果不包装成决策概率。
- [ ] 支持组合可显示真实单模型结果；不存在支持证据时显示原因并允许走补充引擎路径。
- [ ] 本应用创建的受管实例与用户原有接入实例明确区分，为后续启停和退出提供准确归属。
- [ ] 容器行为测试覆盖公开接口响应、能力差异、连接失败和实例归属。
- [ ] 真实 LM Studio 联调与替身测试分别记录，不以替身或框架版本推断支持。
