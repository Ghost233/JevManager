# 06 — 两席真实并发咨询与等权综合

**要构建什么：** 用户选择实际就绪席位，输入上下文和具有稳定 ID 的候选项，看到真实多模型并发意见、等权综合评分、并列最高项、票数和分歧。依据 [首版规格](../../jevmanager/spec.md)，先让两个不同模型完成成功路径，接口与 UI 使用同一业务逻辑。

**被什么阻塞：** [05 — 兼容补充引擎让决策资产实际就绪](05-compatible-engine.md)。

**状态：** ready-for-agent

- [ ] 席位可配置，不硬编码三个品牌，也不沿用原型固定候选项和假概率。
- [ ] 同一请求使用一致的席位/候选快照，向已就绪实例并发派发，不逐席等待或临时下载/加载。
- [ ] 输出覆盖相同候选 ID 的真实概率；身份、展示顺序和不同接口映射不混淆。
- [ ] 对成功概率等权平均，返回完整综合评分和所有并列最高项，不称真实正确率或校准置信度。
- [ ] 保留每席原始答案/概率、实际模型修订、引擎/提供方、耗时与选择，附票数及首选投票分歧。
- [ ] 容器行为测试以受控响应验证并发派发、ID 映射、公式和并列项，不只测试私有算术函数。
- [ ] 至少两种真实模型的成功调用有派发/完成时间与原始结果证据，不因派发并发承诺 GPU 同时执行或耗时下降。
