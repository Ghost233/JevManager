# 03 — 共享模型库的扫描、识别与手动删除

**要构建什么：** 用户选择已有模型库（包括 LM Studio 共用目录），在紧凑模型表格中查看真实资产、完整性和待引擎检查状态，并手动删除明确选中的可删除文件。依据 [首版规格](../../jevmanager/spec.md)，用已有资产即可演示，不要求先完成新下载。

**被什么阻塞：** [01 — 紧凑桌面里的 HF 搜索与文件浏览](01-hf-search-files.md)，使用其正式应用、共用业务入口和验证路径。

**状态：** ready-for-agent

- [ ] 扫描仅处理用户选定目录，不自动搬迁、复制、重命名或覆盖现有模型。
- [ ] 依据文件格式、架构、decision metadata、head/tokenizer/模板及必要配套文件识别，而非仅凭名称或扩展名。
- [ ] 已发现、完整安装、待能力验证、不支持/未知、普通聊天模型与缺文件状态清晰分开，不虚构就绪。
- [ ] 有已知 manifest 时核对来源和指纹，没有上游证据不宣称来源已验证。
- [ ] 用户可手动删除已有或新下载资产；展示所选文件与大小，取消不改变文件，不递归删除整个库，已知在用文件先停用。
- [ ] 容器行为测试用实际临时文件覆盖完整、拆分、缺失、损坏、未知资产与删除边界。
- [ ] 在选定共享目录上完成 Mac 联调，证明扫描保持文件内容/路径及正确列表状态。
